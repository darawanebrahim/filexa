# Filexa Ultra Sprint 14.1 — File Explorer Pro

## Added
- Dedicated File Explorer Pro page inside the managed Filexa directory.
- Folder navigation with safe root boundary.
- Breadcrumb navigation and recent locations.
- Back navigation that returns to the parent folder before leaving the page.
- Create folder.
- Open folders and files.
- Rename files and folders.
- Delete individual or multiple files/folders with confirmation.
- Multi-select and Select All.
- Hidden file visibility toggle.
- List and grid layouts.
- Sort by name, newest, oldest, and size.
- File details and sharing.
- Bottom-safe padding for navigation and gesture areas.

## Integration
Open Files and tap the tree icon in the top bar.

`1.14.1+26`
