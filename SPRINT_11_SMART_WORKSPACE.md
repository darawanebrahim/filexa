# Filexa Sprint 11 — Smart Workspace

Version: `1.11.0+23`

## Added
- Smart Workspace with Cleaner, Insights, and Assistant tabs.
- Duplicate candidate detection using matching file names and sizes.
- Old download review for files older than 30 days.
- Large-file review for files at least 100 MB.
- Safe multi-file deletion with explicit confirmation.
- Storage mix and largest-file insights.
- Private on-device Filexa Assistant for file statistics.
- New Smart Cleaner and Assistant actions on Home.

## Safety
- Filexa never deletes files automatically.
- Duplicate results are candidates, not guaranteed byte-for-byte matches.
- Online generative AI is not included in this sprint.
