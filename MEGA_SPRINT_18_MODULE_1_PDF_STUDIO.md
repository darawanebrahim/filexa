# Filexa Mega Sprint 18 — Module 1: PDF Studio Foundation

Version: 1.18.1+34

## Added
- Dedicated PDF Studio page.
- PDF discovery from Filexa local file index.
- PDF search.
- All/Favorites segmented filter.
- Persistent PDF favorites through Filexa metadata storage.
- Newest, oldest, name and largest sorting.
- List and grid layouts.
- PDF dashboard metrics: total PDFs, favorites and managed storage.
- Read PDF using the best viewer currently available on the Android device.
- Share PDF.
- Copy PDF file location.
- PDF information sheet with name, size, modified date and path.
- Responsive, SafeArea-friendly bottom sheets and scrollable layouts.
- PDF Studio shortcut on Home.
- PDF Studio command in Command Palette.

## Scope note
This module intentionally establishes the stable PDF workspace first. Destructive PDF editing (merge, split, page rewriting, text mutation, signatures written into the PDF) is not falsely exposed until the project has a tested PDF manipulation engine. Those tools are planned for the next PDF module.
