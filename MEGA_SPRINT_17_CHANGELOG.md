# Mega Sprint 17 — Smart Action Center Foundation

## Added
- New Filexa Action Center with global file search and type filters.
- Context-aware actions for PDF, images, media, code, archives, apps and documents.
- Smart Open chooses Filexa HTML/Code viewers where supported.
- PDF quick tools: open, share, copy location and inspect information.
- Persistent favorite toggle through the existing metadata provider.
- Copy file location and detailed file information.
- Action Center shortcut on Home and Command Palette.
- Smart actions entry in the Files action sheet.

## Stability
- All new sheets use SafeArea and scrollable content.
- Async actions check mounted context before showing UI.
- No new external dependency was added.
