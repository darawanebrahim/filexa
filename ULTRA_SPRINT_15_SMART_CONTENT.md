# Filexa Ultra Sprint 15 — Smart Content

Version: `1.15.0+31`

## Features delivered

1. Smart clipboard watcher while Filexa is active.
2. Automatic direct-file URL detection for documents, media, archives, apps, code and subtitle files.
3. Safe download confirmation sheet with source domain and suggested filename.
4. Prefilled New Download sheet after accepting a clipboard suggestion.
5. Clipboard detection switch connected to the global app controller.
6. One-page File Home with Photos, Documents, Apps, Videos, Audio, Archives and Favorites sections.
7. Horizontal recent-file previews and View all navigation for every section.
8. Internal HTML viewer with reload, source view and share.
9. Internal code/text viewer for HTML, CSS, JavaScript, JSON, XML, PHP, Markdown, YAML, Dart, TXT, logs, CSV and subtitle files.
10. Code search with live match count and highlighted matches.
11. Code viewer line numbers, line wrapping and adjustable text size.
12. Smart file opening based on extension.
13. Open as text/code action for any managed file.
14. Additional downloadable extensions including HTML, code and subtitle formats.
15. Responsive scrollable File Home cards with safe bottom spacing.

## Safety and limitations

- Clipboard detection only prompts for direct HTTP/HTTPS file links with recognized extensions.
- PHP is displayed as source code; it is not executed locally.
- Local HTML can be previewed. JavaScript is enabled inside the local viewer.
- OCR and translation remain planned modules and are not represented as completed in this build.
